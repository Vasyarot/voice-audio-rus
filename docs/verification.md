# Проверка Voice Studio

Дата: 2026-10-26. Профиль: `desktop`. GUI: `http://127.0.0.1:11387` (после перезапуска).

## Проверено автоматически

1. `tools/whisper-test.mjs` — локальный Whisper-провайдер с подменёнными `fetch` и
   `sherpa-onnx`: скачивание файлов с прогрессом, фаза `ready`, разбор WAV, язык `ru`,
   автоопределение (`language: ''`), результат транскрипта.
2. `tools/unit-test.mjs` — текст (пунктуация, словарь, заикания), WAV, ресемплинг,
   гейт/AGC.
3. `tools/smoke-client.mjs` — эмуляция загрузчика, `apply(ctx)`, регистрация слотов,
   SSR-рендер кнопки микрофона и страницы настроек.
4. Хост-`apply` с локальной конфигурацией: регистрируются `whisper-tiny`,
   `whisper-base`, `whisper-small` и облачный провайдер; sherpa грузится лениво.

## Что изменилось в этой итерации

- Удалён провайдер SenseVoice и строка `voice-studio-sensevoice` из патча.
- Добавлен `whisper-local.js`: скачивание моделей (HF/hf-mirror), подготовка с
  прогрессом/отменой, ленивая загрузка `sherpa-onnx` из установки DSH.
- `defaultProvider: whisper-base`, язык по умолчанию `ru`.
- В настройках: три локальные модели + облако, подсказка про размеры.

## Не проверено (нужен перезапуск DSH)

Живая активация новых строк и загрузка клиентского бандла. После перезапуска:

1. В настройках плагина виден список провайдеров `Whisper TINY/BASE/SMALL` и облако.
2. «Подготовить модель» качает файлы с прогрессом, затем статус «готов».
3. Клик по микрофону → запись → текст в черновике.
4. Если sherpa не резолвится, статус станет «ошибка: …» — проверить
   `locateSherpa()` и путь установки DSH.

## Откат

Бэкапы профиля: `%USERPROFILE%\.dsh\profiles\desktop\.backup-voice-studio\`.
`dsh plugin --profile desktop remove dsh-plugin-voice-studio` + перезапуск.
