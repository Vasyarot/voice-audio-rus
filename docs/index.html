Voice Audio Rus

Голосовой ввод для DeepSeek Harness с локальным Whisper. Русский язык — приоритет: шумоподавление RNNoise, живой тест микрофона в дБ, калибровка шума и сравнение движков распознавания. Текст можно получать в реальном времени — он дописывается в черновик сразу, каждые ~1.5 с речи, а режим и модель менять прямо у микрофона (правый клик по кнопке).

🎙

Диктовка в композер

Кнопка микрофона, таймер, уровень, вставка текста с проверкой ревизии черновика.

⏱

Текст в реальном времени

Живой режим дописывает распознанное в черновик каждые ~1.5 с речи — сам, без кнопки «Вставить».

🎛

Меню у микрофона

Удержание кнопки — «Записать» / «В реальном времени», модель и язык; правый клик — полные настройки.

🔵

Видно режим

Значок у микрофона и в строке записи: живой режим или по кнопке, и через сколько тишины запись остановится.

🔇

Чистый звук

RNNoise, обрезной фильтр, шумовой гейт и AGC. Одна кнопка включает всю цепочку.

📈

Тест микрофона

Уровень до и после подавления, децибелы, калибровка «Обрезать шум» в один клик.

🧪

Сравнение провайдеров

Одна запись — все готовые движки распознают её независимо: текст, задержка, ошибки.

Установка одной командой · без клонирования
# Windows (PowerShell)
irm https://raw.githubusercontent.com/Vasyarot/voice-audio-rus/main/install.ps1 -OutFile "$env:TEMP\voice-audio-rus.ps1"
powershell -ExecutionPolicy Bypass -File "$env:TEMP\voice-audio-rus.ps1"

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Vasyarot/voice-audio-rus/main/install.sh | bash

Скрипт скачивает исходники с GitHub, сам находит dsh, выбирает профиль (desktop или web), ставит пакет и добавляет бандл в dsh.profile.bundles. Флаги: --profile, --copy, --uninstall, --version, --dry-run. Повторный запуск обновляет плагин.
