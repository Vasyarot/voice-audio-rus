# Варианты локального распознавания речи (STT) для Voice Studio

Ниже — что можно поставить вместо SenseVoice. Все варианты работают офлайн после
скачивания модели; качество русского указано по свободной речи, а не по командам.

| Движок | Русский | Размер модели | Качество ru | Скорость на CPU | Как встроить |
|---|---|---|---|---|---|
| **Whisper tiny/base/small** (ONNX + sherpa-onnx) — **уже в плагине** | да | 100 / 155 / 360 МБ (int8) | базовое / хорошее / очень хорошее | средняя (base ≈ 1–3× реального времени) | ничего ставить не нужно: `sherpa-onnx` входит в DSH |
| Whisper large-v3 / turbo (ONNX) | да | 1.5–3 ГБ | отличное | медленно на CPU | тот же провайдер, крупнее файлы |
| **Vosk** small / big | да | 45 МБ / 1.8 ГБ | хорошее для диктовки, слабее в спонтанной речи | очень быстро (потоково) | отдельный native-модуль или `vosk-browser` (WASM) |
| **GigaAM v2** (Sber) | да (лучший ru) | ~250–900 МБ | лучшее среди открытых ru | средне | ONNX Runtime + конвертация модели |
| **Silero STT** | да | ~50 МБ | хорошее | быстро | ONNX, простой API |
| **Moonshine** tiny/base | нет | 27–60 МБ | — | быстро | только английский |
| **Parakeet TDT 0.6B** (NVIDIA) | нет | ~600 МБ | — | быстро на GPU | только английский |
| **transformers.js Whisper** (в браузере) | да | 40–250 МБ | как у Whisper (квант.) | медленно в WASM, быстрее в WebGPU | без хоста, но +несколько МБ бандла и загрузка из CDN |
| **Vosk-browser** (WASM) | да | 45 МБ | как Vosk | средне | целиком в браузере |
| Облако: OpenAI `whisper-1`/`gpt-4o-transcribe`, Deepgram | да | 0 | отличное | мгновенно | нужен ключ и интернет |

## Что рекомендую

1. **По умолчанию — Whisper `base` int8 (155 МБ).** Лучший баланс «скачал один раз →
   работает офлайн, русский есть, качество заметно выше tiny». Уже реализовано.
2. **Максимум качества офлайн — `small` (360 МБ).** Дольше распознаёт, но заметно точнее
   на именах, терминах и пунктуации. Включён в список моделей плагина.
3. **Быстрые короткие команды — `tiny` (100 МБ).** Мгновенный старт, но ошибки на
   сложных словах.
4. **Если нужна лучшая точность без ожидания — облачный провайдер** (ключ на хосте,
   аудио не уходит в браузер). Локальные модели при этом остаются как запасной путь.
5. **Если принципиален только русский и максимальное качество офлайн** — добавить
   провайдер GigaAM v2: по качеству на русском он обычно лучше Whisper small,
   но требует конвертации модели в ONNX и ~0.5–1 ГБ на диске.

## Почему выбран Whisper через sherpa-onnx

- `sherpa-onnx` и его Windows-рантайм **уже поставляются с DSH** — не нужно тащить
  второй native-стек и подписывать бинарники.
- Whisper поддерживает русский, пунктуацию и автоопределение языка.
- Модели лежат на Hugging Face (есть зеркало hf-mirror) — скачивание по кнопке,
  прогресс и отмена уже реализованы в плагине.
- Один и тот же провайдер легко расширить до `large-v3-turbo`, поменяв `models`
  в конфиге.

## Ограничения

- Whisper не потоковый: распознаётся запись целиком (до 5 минут в текущем конфиге).
- На CPU `small` может быть медленнее реального времени на слабых машинах.
- Языки кроме ru/en нужно включить в `languages` провайдера (список в патче).
