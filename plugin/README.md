# Voice Audio Rus для DeepSeek Harness

Русский язык — приоритет: локальный Whisper, `ru` по умолчанию, шумоподавление и тест микрофона.

Голосовой ввод в духе встроенного `voice-input`, но с панелью звука, шумоподавлением,
локальным Whisper и расширенными улучшениями.

## Возможности

- Кнопка микрофона в композере → запись → распознавание → вставка в черновик
  (с проверкой ревизии: при конфликте текст можно вставить вручную).
- **Режим реального времени**: текст дописывается в конец черновика сразу, кусками
  по ~1.5 с речи (и раньше, если вы замолчали). Кнопки «Вставить» больше нет: вставка
  повторяется сама, пока черновик не примет текст. Остановка — вручную или по тишине
  (переключатель «Остановка по тишине» в разделе «Режим диктовки»).
- **Два меню у микрофона**: удержание кнопки — только выбор режима («По кнопке» /
  «В реальном времени»), правый клик — модель, язык, облачные параметры, **выбор
  микрофона и его проверка** и ссылка на все настройки.
- **Выбор и проверка микрофона в ПКМ-меню**: список устройств («Автоматически» +
  все входы), кнопка «Проверить» слушает выбранный микрофон 3 секунды, показывает
  уровень и вердикт «слышу» / «тишина». Список запрашивается только при открытии
  меню, поэтому на запуск DSH это не влияет.
- Живая панель записи: таймер, индикатор уровня, значок режима, отмена, повтор, «Стоп».
- Звук: выбор микрофона, RNNoise (WASM, регулируемая сила), high-pass, шумовой гейт,
  AGC, входное усиление, лимитер, фейды.
- Тишина и клавиши: авто-стоп по тишине (VAD), push-to-talk (удержание/переключение).
- Текст: авто-пунктуация, удаление заиканий, словарь замен.
- Провайдеры:
  - **Whisper локально** (Whisper tiny/base/small, ONNX на CPU через `sherpa-onnx`,
    который уже входит в DSH) — офлайн, русский поддерживается;
  - **облако** — OpenAI-совместимый `/audio/transcriptions` (ключ на хосте).

## Установка

**Из репозитория (рекомендуется):**

```powershell
git clone https://github.com/Vasyarot/voice-audio-rus.git
cd voice-audio-rus
.\install.ps1
```

Скрипт скачивает архив `Vasyarot/voice-audio-rus`, ставит пакет из `plugin/` в профиль и
добавляет бандл. Параметры: `-Profile <имя>`, `-Copy` (копировать файлы вместо симлинка —
нужно для desktop-профиля), `-Version <ветка|тег>` (по умолчанию `main`).
Справка: `.\install.ps1 -?`.

**Вручную:** скачайте zip репозитория, распакуйте и добавьте папку `plugin`:

```powershell
dsh plugin --profile web add "file:<путь>\voice-audio-rus\plugin"
```

Desktop-профиль ставится через «Настройки → Плагины»: CLI этим профилем не управляет
(`profile "desktop" is managed exclusively by the Electron application`).

Откат: `dsh plugin --profile web remove dsh-plugin-voice-studio`. После установки
**перезапустите DSH**.

> Не включайте одновременно официальный `@deepseek-ai/dsh-experimental-voice-input-bundle`.

## Локальные модели

В плагине три локальных провайдера — выберите модель в настройках:

| Провайдер | Размер загрузки | Когда выбирать |
|---|---|---|
| `Whisper TINY` | ≈ 100 МБ | быстрый старт, короткие команды |
| `Whisper BASE` | ≈ 155 МБ | баланс по умолчанию |
| `Whisper SMALL` | ≈ 360 МБ | максимум качества офлайн |

Модель скачивается один раз кнопкой «Подготовить модель» (Hugging Face или зеркало
hf-mirror), кэш лежит в `%USERPROFILE%\.dsh\speech-to-text\whisper\<model>`.
Подробное сравнение движков (Vosk, GigaAM, Silero, Whisper, облако) —
в [docs/local-stt-options.md](../docs/local-stt-options.md).

## Список провайдеров

В «Модели распознавания речи» четыре строки, в этом порядке:

| id | Подпись | Что делает |
|---|---|---|
| `whisper-tiny` | Whisper TINY · локально | офлайн, быстро |
| `whisper-base` | Whisper BASE · локально | офлайн, по умолчанию |
| `whisper-small` | Whisper SMALL · локально | офлайн, точнее |
| `cloud-openai` | Облако · OpenAI-совместимый | свой Base URL, модель и ключ |

Отдельных строк DeepSeek в списке нет: у DeepSeek нет распознавания речи — в API
платформы аудио-эндпоинтов нет (`/api/v0/audio/*`, `/api/v0/asr` отвечают `404`),
в документации `api-docs.deepseek.com` аудио не упоминается, а в чат-клиенте из
47 путей API есть только синтез речи `/api/v0/chat/tts/*`. Поэтому локальный
Whisper остаётся единственным способом работать без ключа, а облако — любым
OpenAI-совместимым сервером.

## Облачный провайдер

```powershell
[Environment]::SetEnvironmentVariable('OPENAI_API_KEY', 'sk-...', 'User')
```

Либо переопределите строку `voice-studio` в
`%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`: `cloud.baseURL`, `cloud.model`,
`cloud.apiKeyEnv` / `cloud.apiKey`.

Список моделей подтягивается автоматически, как только заполнены Base URL и ключ: плагин
запрашивает `<Base URL>/models`, помечает рекомендацию «★ лучшая для речи» и сразу её
выбирает. Ключ сохраняется в credentials DSH, в конфиг попадает только имя ссылки.

## Приватность

- Аудио живёт в памяти вкладки и в запросе к выбранному провайдеру.
- Локальные модели обрабатывают звук на машине хоста, без сети после загрузки.
- Распознанный текст не сохраняется: он сразу вставляется в черновик.
